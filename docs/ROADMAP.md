# 开发路线图

## 已实现

- [x] SwiftPM 工程、macOS 14 最低运行版本与应用身份
- [x] 历史业务、界面状态、持久化和系统适配边界
- [x] 严格并发检查、格式规则、单元测试和基础 CI
- [x] 文本/URL/图片/文件采集、去重、搜索、固定与删除
- [x] 后台 OCR/二维码识别

- [x] MIT、CHANGELOG、贡献与发布说明
- [x] Developer ID、公证、校验和与符号归档脚本及手动 workflow
