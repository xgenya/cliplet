# 产品需求文档

## 1. 产品愿景

构建一款快速、可靠、尊重隐私的原生 macOS 剪贴板管理器。用户按下全局快捷键后，应能在极短时间内找到最近复制的内容，并完成预览、复制或直接粘贴。

## 2. 目标用户

- 高频复制文本、链接和代码的开发者
- 需要在多个文档间搬运内容的知识工作者
- 需要搜索和复用历史素材的设计师与内容创作者

## 3. MVP 范围

### 3.1 剪贴板采集

- 监听系统剪贴板变化
- 支持纯文本、富文本、URL、图片和文件引用
- 记录来源应用、创建时间和内容类型
- 重复内容去重，保留原条目的固定状态与自定义名称
- 可配置历史保留时长与最大条数

### 3.2 搜索与浏览

- 全局快捷键呼出浮层
- 关键词即时搜索
- 按内容类型过滤
- 列表展示内容摘要、来源应用、时间和类型图标
- 右侧或弹出式快速预览

### 3.3 操作

- 回车复制或粘贴选中内容
- 固定与取消固定
- 删除单条记录
- 清空未固定历史
- 在来源应用或浏览器中打开适用内容

### 3.4 隐私控制

- 排除指定应用
- 暂停记录
- 对疑似密码、验证码等敏感内容提供可配置策略
- 所有历史默认仅保存在本机

## 4. 非目标（MVP）

- 跨设备云同步
- 团队共享剪贴板
- AI 总结或内容改写（图片 OCR 仅用于搜索，不改写内容）
- Windows、iOS 与 iPadOS 客户端
- 第三方插件系统

## 5. 关键交互

1. 用户复制内容。
2. 应用检测 `NSPasteboard.changeCount` 变化并读取支持的数据类型。
3. 内容标准化、去重并落盘。
4. 用户按全局快捷键打开浮层。
5. 用户输入关键词或使用方向键选择。
6. 回车将内容写回剪贴板；在已授权时，可自动粘贴到原应用。

## 6. 体验指标

- 热启动呼出延迟目标：低于 100 ms
- 10,000 条记录下的搜索响应目标：低于 50 ms
- 空闲状态 CPU 占用应接近 0%
- 常规数据库规模下内存占用目标：低于 150 MB
- 不应记录来自排除应用的任何正文数据

## 7. 决策记录

已决定：

- 默认快捷键为 ⌥V
- 存储采用版本化 JSON 元数据加独立附件文件；数据规模增长后再评估数据库与全文索引
- 自动粘贴默认开启，未授予辅助功能权限时仍写入剪贴板

待决策：

- 敏感内容检测的规则与误报处理
- 图片历史的默认保留时长和存储上限
